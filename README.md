# Proyecto RetailPro - Data Analytics

Repositorio correspondiente a los entregables y prácticas del módulo de análisis de datos, enfocado en la gestión de bases de datos, consultas SQL avanzadas y procesos ETL.

## Contenido del Repositorio
* **`m4_consultas_negocio.sql`**: Consultas individuales sobre las tablas de negocio.
* **`m5_consultas_joins.sql`**: Consultas con `JOINs`, `LEFT JOIN` y `UNION ALL` para enriquecer la vista de datos.
* **`Entregable 3.sql`**: Script base de creación de tablas, inserción de datos y consultas iniciales.

## 🛠️ Tecnologías Utilizadas
* **SQL** (Modelado y consultas)
* **Power BI / Power Query** (ETL y visualización)
