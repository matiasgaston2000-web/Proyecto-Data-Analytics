## 👋 Introducción
¡Bienvenido/a! Este repositorio reúne los trabajos que fui desarrollando durante el curso de **Data Analytics**, a partir del proyecto **RetailPro**. Cada entrega suma una etapa del proceso de análisis, desde la definición del problema hasta la visualización de resultados.

## 🎯 Descripción
**RetailPro** es un proyecto integrador en el que se trabaja con datos de ventas para responder preguntas de negocio. A lo largo del curso se recorren las etapas habituales del trabajo de un analista de datos:

- 🧭 Definición del problema y del alcance del proyecto
- 🗄️ Diseño y modelado de la base de datos
- 🔎 Consultas SQL para obtener información de negocio
- 🔄 Limpieza y transformación de datos (ETL)
- 📈 Modelado y visualización en Power BI

## 📦 Entregas
Dentro del repositorio hay una carpeta llamada **`Entregas`**, donde se encuentran las entregas del curso. Cada una corresponde a una etapa del proyecto:

- ✅ **Brief** del proyecto RetailPro
- ✅ **Modelo de datos** RetailPro
- ✅ **Script SQL** para esquema normalizado y datos iniciales
- ✅ **Consultas SQL** de negocio
- ✅ **Consultas con JOINs** para el proyecto
- ✅ **Pipeline ETL** con Power Query y M
- ✅ **Boceto del dashboard** RetailPro
- ✅ **Modelo de datos** con relaciones activas y medidas core en DAX

> 🔜 Las nuevas entregas se van sumando a medida que avanza el curso.
